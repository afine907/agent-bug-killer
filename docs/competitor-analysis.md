# 竞品分析 — Agent Bug Killer 定位

## 直接竞品

### 1. Sentry
**优势：**
- 成熟的错误监控平台
- 广泛的语言/框架支持
- 强大的错误分组和聚合
- 性能监控
- 开源 (self-hosted 可选)

**劣势：**
- 主要是错误收集，不是诊断
- 没有 AI 驱动的根因分析
- 配置复杂
- 价格昂贵（SaaS）

**我们能学的：**
- 错误分组和聚合
- Source Map 支持
- Release tracking
- Breadcrumb trail

### 2. Datadog
**优势：**
- 全栈可观测性（APM, Logs, Metrics）
- 强大的关联分析
- ML 驱动的异常检测
- 丰富的集成

**劣势：**
- 极其昂贵
- 学习曲线陡峭
- 闭源
- 资源消耗大

**我们能学的：**
- 分布式追踪
- Log-Metric-Trace 关联
- Dashboard 可视化

### 3. LangSmith
**优势：**
- LLM 应用专用监控
- Trace 可视化
- 评估和测试框架
- LangChain 生态集成

**劣势：**
- 只针对 LLM 应用
- 不是通用 Bug 诊断
- 闭源 SaaS

**我们能学的：**
- LLM Trace 可视化
- 评估框架
- Prompt 调试

### 4. Grafana + Loki
**优势：**
- 开源
- 强大的日志查询
- 可视化优秀
- 社区活跃

**劣势：**
- 需要自己搭建
- 没有 AI 诊断
- 配置复杂

**我们能学的：**
- PromQL 查询语言
- Dashboard 设计
- 告警规则

## 我们的差异化

### 核心差异：AI-First 诊断

| 特性 | 我们 | Sentry | Datadog | LangSmith |
|------|------|--------|---------|-----------|
| AI 根因分析 | ✅ | ❌ | 部分 | ❌ |
| 多源关联 | ✅ | ❌ | ✅ | ❌ |
| 修复建议 | ✅ | ❌ | ❌ | ❌ |
| 知识库 | ✅ | ❌ | ❌ | ❌ |
| 开源 | ✅ | ✅ | ❌ | ❌ |
| Agent 框架 | ✅ | ❌ | ❌ | ❌ |
| 本地部署 | ✅ | ✅ | ❌ | ❌ |

### 我们的独特价值

1. **AI-First**: 不是事后分析，是实时诊断
2. **多源关联**: SSH + CDP + Code + Logs
3. **修复建议**: 不只告诉你什么坏了，还告诉你怎么修
4. **知识库**: 学习历史问题，越用越聪明
5. **Agent 框架**: 可扩展的诊断 Agent
6. **完全开源**: 无 vendor lock-in
